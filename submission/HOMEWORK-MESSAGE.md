# Сообщение для сдачи домашнего задания

Проект «Ритм» — ИИ-гид по фитнес-программам для взрослых пользователей.

**Что получилось реализовать.** Созданы сайт и Telegram-бот @ritm_fitness_bot, подключён GigaChat через API. Ассистент собирает анкету, составляет недельную программу с учётом цели, опыта, времени и оборудования, объясняет упражнения и предлагает изменения по обратной связи. Новая версия принимается пользователем, предыдущая сохраняется в истории. Разработаны промпты подбора, объяснения и исправления ответа. Дозировка, расписание и оценка времени формируются и проверяются сервером. Пройдены 28 автоматических тестов; в серии на одной синтетической анкете успешны 5 из 5 созданий и 5 из 5 адаптаций через настоящий API.

**Что пока не выполнено.** Не настроен публичный хостинг для круглосуточной работы; сайт и бот требуют запущенных локальных процессов. Нет привязки профиля сайта к Telegram. Каталог ограничен 12 упражнениями; нужна более широкая проверка разных целей и ограничений, включая дополнительные сценарии обработки боли и переноса упражнений между днями.

**Планы развития.** Расширить каталог с участием тренера, доработать указанные проверки, провести тестирование на разнообразных учебных анкетах, связать профили и развернуть приложение на сервере.
