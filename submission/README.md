## Формат сдачи

В сообщение к домашнему заданию вставьте текст из HOMEWORK-MESSAGE.md и ссылку
на эту папку GitHub. В ней размещены коммерческое предложение со скриншотами,
описание, промпты и подтверждающие материалы. Сценарий пригодится, если нужен
дополнительный живой показ или видео; в уточнённых требованиях видео не указано.

Видео не записано. В screenshots/ находятся четыре скриншота действующего
интерфейса на сохранённых результатах реального API-теста с вымышленной анкетой.
Это не новые вызовы модели. Исходный пример и пояснения — DEMO-EXAMPLE.md.

Сайт работает локально: http://127.0.0.1:8000/. Этот адрес доступен на компьютере
с запущенным сервером. Преподаватель может запустить код по SETUP.md или
посмотреть демонстрацию. Бот: https://t.me/ritm_fitness_bot — отвечает, пока
работает его процесс и есть подключение к Telegram/GigaChat.

запуска архив не зависит от объединения PR.

## Пересборка материалов

Из корня проекта: `python prepare_submission.py`.
Команда обновляет экспорт промптов, пример и ZIP по сохранённым доказательствам;
не обращается к модели, не отправляет сообщения и не читает .env.

PDF собирается отдельно: `python tools/build_proposal.py` (нужны ReportLab,
Pillow и шрифты Arial в Windows). Демонстрационный сервер для скриншотов:
`python tools/proposal_demo.py`, адрес http://localhost:8001/demo. Он использует
отдельную учебную базу и сохранённый evidence.json, без вызовов модели.
