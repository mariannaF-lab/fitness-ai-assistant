## Формат сдачи

Передайте ZIP проекта, описание, промпты и демонстрацию экрана — живой показ
или записанное видео по сценарию. Если платформа курса требует определённый
формат, перенесите отчёт в него; содержание уже подготовлено.

Видео и скриншоты в этом пакете не записаны. DEMO-EXAMPLE.md — сохранённый
результат реального API-теста, а не видеодемонстрация и не новый живой запрос.

Сайт работает локально: http://127.0.0.1:8000/. Этот адрес доступен на компьютере
с запущенным сервером. Преподаватель может запустить код по SETUP.md или
посмотреть демонстрацию. Бот: https://t.me/ritm_fitness_bot — отвечает, пока
работает его процесс и есть подключение к Telegram/GigaChat.

## Исходный код

Репозиторий: https://github.com/mariannaF-lab/fitness-ai-assistant

Полная реализация находится в ветке
[implement-fitness-assistant](https://github.com/mariannaF-lab/fitness-ai-assistant/tree/implement-fitness-assistant).
Ветка main содержит навык разработки; PR №1 с приложением ещё не объединён.
В ZIP вложены сами исходники приложения, тесты и навык, поэтому для локального
запуска архив не зависит от объединения PR.

## Пересборка материалов

Из корня проекта: `python prepare_submission.py`.
Команда обновляет экспорт промптов, пример и ZIP по сохранённым доказательствам;
не обращается к модели, не отправляет сообщения и не читает .env.
