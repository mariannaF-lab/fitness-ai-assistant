# Запуск сайта и Telegram-бота

## Подготовка

Требуется Python 3.10 или новее. Из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` в редакторе. Впишите Authorization key в `GIGACHAT_CREDENTIALS`,
название доступной модели — в `GIGACHAT_MODEL`. Например, если она доступна
в вашем аккаунте, `GigaChat-3-Ultra`. Scope для физического лица:
`GIGACHAT_API_PERS`. Access token вручную вставлять не нужно: сервер получает
и обновляет его автоматически.

При ошибке доверия сертификату настройте PEM-пакет через
`GIGACHAT_CA_BUNDLE` согласно официальной инструкции GigaChat. Проверка TLS
не отключается.

## Сайт

```powershell
.\.venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:8000. Можно заполнить анкету без ключа;
генерация станет доступна после настройки GigaChat и перезапуска сервера.
Ответы сохраняются в `data/fitness.db`, а доступ к профилю определяется
cookie браузера. При удалении cookie доступ к прежнему веб-профилю теряется;
регистрация и восстановление доступа не входят в прототип.

## Telegram

1. В Telegram откройте официальный @BotFather и создайте бота командой /newbot.
2. Вставьте выданный токен в `TELEGRAM_BOT_TOKEN` локального `.env`.
3. Необязательно укажите `TELEGRAM_BOT_USERNAME` без @ для ссылки на сайте.
4. В отдельном терминале запустите:

```powershell
.\.venv\Scripts\python.exe bot.py
```

Откройте своего бота и отправьте /start. /profile начинает анкету,
/resume продолжает незавершённую. /generate создаёт программу, /program
показывает текущую. /feedback сохраняет отзыв, /adapt предлагает изменения,
/history показывает версии. /confirm НОМЕР принимает предложенную версию.
Сайт и бот используют общую бизнес-логику, но отдельные профили.

Держите запущенным только один процесс polling для одного Telegram-токена.
После выключения компьютера локальный бот перестаёт отвечать.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Автотесты используют подменный LLM-клиент и HTTP MockTransport, не расходуют
токены. Живой запрос проверяется вручную после настройки ключа: заполните
анкету и создайте программу. Успешный запуск сервера не подтверждает доступ
к модели. Полный план содержательной приёмки — в
`skills/build-fitness-assistant/references/acceptance.md`.

## Границы прототипа и размещение

Реализованы недельная программа для взрослых, объяснения, отзывы,
подтверждаемая адаптация и история версий. Анкеты и отзывы хранятся локально,
без автоматического удаления; оператор отвечает за удаление и резервные
копии. Секреты, данные и `.env` исключены из Git. Перед публичным запуском
нужны политика обработки данных, срок хранения, удаление профиля,
ограничение запросов и эксплуатационная проверка рекомендаций.

Это Python-приложение. Для постоянной работы нужен хостинг с Python,
постоянным диском и исходящим HTTPS к GigaChat и Telegram. Размещайте сайт
через production WSGI-сервер за HTTPS, задайте `COOKIE_SECURE=true`;
`python app.py` — только локальный запуск. Бот работает отдельным процессом.
Статический хостинг сам по себе сервер и бота не запускает.

Официальная авторизация GigaChat:
https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api
