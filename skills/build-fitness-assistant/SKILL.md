# Создание ИИ-гида по фитнес-программам

Помогай создавать работающего ассистента: анкета → недельный план → объяснение упражнения → отзыв → подтверждаемая адаптация. Общайся по-русски, объясняй решения для защиты учебного проекта.

## Основа проекта

- Первая версия — взрослые от 18 лет, недельные планы.
- Сайт: вводный блок, три шага анкеты и четвёртый шаг подтверждения. Отдельный лендинг не требуется.
- Фактический стек исходного проекта: Python 3.10+, Flask, python-telegram-bot, Pydantic 2, SQLite, httpx. FastAPI и aiogram были ранним предложением; не мигрируй на них без причины.
- Сайт и бот используют общий сервис, схемы и каталог. Профили каналов отдельны; одинаковое имя не связывает аккаунты.
- Анкету собирает приложение. GigaChat выбирает упражнения по id из доступного каталога и объясняет выбор. Сервер формирует полный план и рассчитывает время.
- Модель объясняет отдельное упражнение. Адаптация использует тот же компактный контракт выбора; сервер хранит предложение до подтверждения.
- Питание, медицинская реабилитация, платежи и браслеты не входят в первую версию. MCP-сервер для обычного сайта и бота не требуется.

Это исходные решения данного проекта, а не обязательный стек для всех ассистентов. В новом окружении сначала установи контекст пользователя. В существующем проекте сохраняй реализацию и ранее данные разрешения; не запрашивай согласование тех же решений заново.

## Маршрут работы

1. Прочитай инструкции репозитория, определи текущую задачу и состояние файлов. Если пользователь просит аудит навыка, ограничь изменения навыком, если не найдена отдельно согласованная ошибка приложения.
2. Для архитектуры, данных и сценариев прочитай [specification.md](references/specification.md).
3. Для создания или адаптации программы прочитай [prompts.md](references/prompts.md). Не возвращайся к генерации полного недельного JSON моделью: это известный источник нестабильности.
4. Для подключения или ошибки API прочитай [gigachat.md](references/gigachat.md). Отделяй сеть, TLS, авторизацию, доступность модели и ошибки ответа.
5. Для тестирования, отчёта и демонстрации прочитай [acceptance.md](references/acceptance.md). Проверяй содержательную пригодность отдельно от JSON и времени.
6. Передай результат, команды запуска, фактически пройденные проверки и оставшиеся ограничения. Файлы навыка сами по себе не устанавливают приложение и не запускают процессы.

Ссылки выше находятся внутри устанавливаемого навыка и достаточны для проектирования с нуля. Если открыт исходный репозиторий, актуальные реализации находятся в `fitness/planner.py`, `fitness/models.py`, `fitness/llm.py`, `fitness/service.py`, `app.py`, `bot.py`. Эти пути относятся к корню проекта, не к установленной папке навыка. Не считай наличие этих файлов гарантированным.

## Инварианты

- Сервер проверяет оба интерфейса, принадлежность данных, обязательные поля и согласие на передачу анкеты. Отказ сообщать ограничения не означает их отсутствие.
- LLM возвращает компактный выбор; неизвестный id и неподходящая структура не становятся готовым планом. Один запрос исправления, затем понятная ошибка без подмены заглушкой.
- Дозировка и оценка времени принадлежат серверу; оборудование фильтруется до обращения к модели. Каталог ограничивает допустимые варианты, но не гарантирует медицинскую пригодность.
- Отзыв сам по себе не меняет программу. Изменения сохраняются как предложение; подтверждение меняет текущую версию и сохраняет предыдущую.
- Секреты остаются в локальном `.env`, не попадают в Git, браузер, чат и журналы. Реальные анкеты не используются как публичные доказательства тестирования.
- Не ставь диагнозы, не назначай лечение, не обещай результат и не предлагай продолжать болезненное упражнение.
- Наличие ключа, ссылки на бота или кнопки на сайте не подтверждает рабочее подключение. Отдельно проверяй процессы, API и сценарии пользователя.
- Навык не расширяет разрешения: используй уже полученную авторизацию на размещение и расходы, а при её отсутствии сначала подготовь проверяемый результат. Не создавай платные ресурсы и не публикуй реальные данные по одному факту вызова навыка.
