# Отчёт тестирования ИИ-гида «Ритм»

Актуальные результаты повторной проверки: [TEST-REPORT-2026-10-19.md](TEST-REPORT-2026-10-19.md).
Ниже сохранено состояние первоначального прогона до исправления подключения.

Дата: 19 октября 2026 года.

## Условия

Приёмка проводится на синтетическом профиле: 28 лет, начинающий,
общая физическая форма, дома, без оборудования, 3 занятия по 30 минут,
пожелание — без прыжков. Анкета и программы помещаются в отдельную временную
базу; существующие пользовательские профили не изменяются.

## Результаты живой проверки

| Сценарий | Ожидается | Фактически | Статус |
|---|---|---|---|
| Сохранение анкеты | Валидный профиль сохранён | Профиль сохранён в изолированной базе | Пройдено |
| Создание программы через GigaChat | 3 занятия до 30 минут, без оборудования | Авторизация остановилась на проверке цепочки сертификатов | Ошибка подключения |
| Сохранность данных при ошибке | Анкета остаётся доступна | Обработанная ошибка, готовая программа не создана | Пройдено |
| Объяснение упражнения через API | Инструкция к упражнению из программы | Не выполнено: программа не получена | Не проверено |
| Обратная связь в полном сценарии | Отзыв привязан к тренировке | Не выполнено: программа не получена | Не проверено |
| Адаптация до 20 минут | Новая версия, ожидающая подтверждения | Не выполнено: программа не получена | Не проверено |
| История реальных программ | Предыдущая версия сохраняется | Не выполнено: программа не получена | Не проверено |

Установлена причина: исходное HTTPS-подключение использовало некорректно
определённый системный прокси; после явной настройки HTTP-прокси проявилась
ошибка CERTIFICATE_VERIFY_FAILED (self signed certificate in certificate chain).

В клиент добавлены отдельный GIGACHAT_PROXY_URL и SSL-контекст с системными
доверенными сертификатами Windows. Проверка сертификатов включена.
Повторная сетевая проверка после исправления не выполнена: пользователь
отклонил запрос разрешения. Исправление не считается подтверждённым.

## Автоматические проверки

19 тестов с подменными API проверяют валидацию анкеты, 18+, CSRF,
изоляцию пользователей, отсутствие ответа об ограничениях, отзывы,
подтверждение адаптации и историю, восстановление диалога бота,
обработку ошибок, структуру JSON, ограничения оборудования и времени,
обновление токена. Они не подтверждают качество реального ответа GigaChat.

## Продолжение приёмки

1. Выполнить `python check_gigachat.py`: ожидается `Authorization OK`.
2. Выполнить `python live_acceptance.py`: запускает реальную генерацию,
   объяснение и адаптацию с расходом токенов GigaChat.
3. Проверить содержимое `reports/live-results.json` и вручную оценить
   полученную программу. Обновить таблицу фактическими результатами.
4. После успешной проверки перезапустить сайт и бота, чтобы они использовали
   обновлённый клиент и настройки.

Полная содержательная проверка рекомендаций и демонстрация в Telegram
пока не завершены. Проверка структуры не заменяет оценку тренером.
