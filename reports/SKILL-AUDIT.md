# Проверка навыка build-fitness-assistant

Дата: 19 октября 2026 года. Редакция навыка: 2.1; контракт промптов: 2.0.

## Найдено и исправлено

| Проблема | Исправление |
|---|---|
| Предпочтение FastAPI и aiogram после реализации на другом стеке | Указан фактический Flask / python-telegram-bot; запрещена необоснованная миграция |
| Старые промпты полного недельного JSON рядом с новым контрактом | Оставлен единый компактный Selection; полный ProgramResult формирует сервер |
| DATABASE_URL, который приложение не читает | Указан FITNESS_DB и фактические настройки прокси, сертификатов и бота |
| Смешение Authorization key и временного токена | Диагностика разделяет сеть, TLS, авторизацию, модель и структуру ответа |
| Ссылки на код репозитория могли выглядеть обязательной частью установленного навыка | Все обязательные инструкции находятся внутри пакета; пути приложения обозначены как контекст |
| Поля и команды описывали проект, а не реализацию | Уточнены черновик, provided/declined, согласие, индексы упражнений и /profile против /resume |
| Проверка JSON могла трактоваться как полная приёмка | Разделены запуск, автотесты, живой API и ручные интерфейсные сценарии |
| Непроверенные универсальные обещания | Отмечены рамки блокировки при боли, сравнения дозировки по занятиям и ограниченного каталога |

## Выполненные проверки

- Штатный quick_validate.py: Skill is valid! Проверены frontmatter, имя и отсутствие незавершённых заготовок.
- Изолированная копия пакета: 4 внутренние ссылки разрешаются внутри папки навыка.
- agents/openai.yaml: корректный YAML, длина описания, ссылка на $build-fitness-assistant; автоматическое обнаружение сохранено.
- JSON-пример Selection: принят настоящей схемой и проверкой допустимых id приложения.
- Названия переменных конфигурации: найдены в текущем коде; неиспользуемый DATABASE_URL убран из шаблона.
- Прочитаны все пять изменённых файлов и проверено соответствие согласованному объёму проекта.

Это проверка пакета и его контрактов, а не независимый запуск полного проекта
другим агентом. Новых живых запросов к модели и изменений приложения не выполнялось.
PyYAML для штатного валидатора установлен в игнорируемую локальную папку
.validation-deps; он не является зависимостью создаваемого приложения или навыка.

В пользовательской папке установленных навыков локальная копия
build-fitness-assistant не обнаружена. Обновляется пакет репозитория;
это не означает автоматическую установку навыка в Codex.

## Отдельные вопросы приложения

Навык теперь требует проверять адаптацию при переносе упражнения между днями,
новую генерацию после сообщения о боли и влияние исторических отзывов. В текущем
коде сравнение дозировки привязано к соответствующему занятию, а детерминированная
проверка боли выполняется в ветке адаптации. Полную защиту всех путей и сценариев
на основании имеющихся тестов утверждать нельзя. Эти пункты отмечены для отдельной
проверки приложения; изменения ограничены документацией навыка и этим отчётом.
